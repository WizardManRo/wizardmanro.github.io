How to Use — Deployment Guide
1

Configure VPN Server Parameters

Go to the Server Side Configuration tab and define your public IP, UDP port, VPN subnet, and NAT masquerade rules. Hover over the info badges for clear networking tooltips.

2

Deploy Server Script on MikroTik

Click the Copy Script button in the IDE code window on the right. Connect to your MikroTik router (via WinBox or SSH) and paste the commands directly into the terminal console. This initializes the server interface, subnet IPs, incoming firewall rules, and NAT masquerade tables.

3

Configure VPN Client Devices

Switch to the Client Side Configurations tab. Quick-add peer names (e.g. my_mobile, office_laptop). Every client gets a dynamically generated VPN IP and cryptographic key pair.

  • Mobile Devices: Click Scan QR / Code on the peer's card, open the official WireGuard app on your phone, click the "+" button, and select Create from QR code to scan.
  • Laptops / PCs: Click .conf on the card to download the client configuration file and import it directly into your computer's WireGuard application.
4

Backup & Persist Deployment State

Before closing the browser, click Export JSON in the top menu bar to download your configuration file. In the future, you can click Import JSON to reimport this state and add new client peers without rotating existing keys or disconnecting active users!
