Server Settings
The public-facing internet address of your router. This is required so remote clients know where to connect to access the VPN.
The UDP port the WireGuard interface listens on. Default: 51820.
Maximum Transmission Unit. Controls packet sizing. Standard WireGuard MTU is 1420 to prevent packet fragmentation.
The virtual interface name on the MikroTik router (Default: wireguard1).
The private IP range used exclusively inside the VPN tunnel (Default: 10.10.0.0/24).
The private IP address of the router inside the VPN tunnel (Default: 10.10.0.1).
Enable NAT Masquerade
Applies NAT to the VPN traffic, enabling clients to browse the general internet using your router's connection.
The interface connected directly to the internet (typically ether1) or an Interface List (typically WAN).
Is WAN an Interface List?
Enable if your WAN parameter refers to a RouterOS Interface List (e.g. 'WAN') instead of a raw hardware port name (e.g. 'ether1').
Route All Client Traffic (Full Tunnel)
Full-Tunnel (Enabled) routes ALL client traffic through the VPN. Split-Tunnel (Disabled) routes ONLY traffic destined for your LAN.
The internal office subnet range (e.g. 192.168.88.0/24). In split-tunnel mode, this range is routed so you can connect to local devices.
DNS servers assigned to clients (e.g. 1.1.1.1, 8.8.8.8).
Sends keepalive packets. Recommended (25 sec) for NAT traversal on mobile clients.
